# Velvet touch — лендинг вакансии SPA-салона

Учебный проект для портфолио: одностраничный лендинг на чистых HTML/CSS/JS без сборки. Компания, тексты и отзывы вымышлены.

## Секции
Шапка с меню · Hero · Преимущества · FAQ (аккордеон) · Условия проживания (галерея) · Отзывы (слайдер) · Связь (Telegram, WhatsApp) · Футер.

## Запуск локально
```bash
npx serve .
```
Или просто откройте `index.html` в браузере.

## Структура
- `index.html` — разметка
- `styles.css` — стили и адаптив (брейкпоинты 1080 / 960 / 720 px)
- `script.js` — мобильное меню, аккордеон, слайдер
- `assets/img/` — фотографии (см. `assets/img/README.md`)

## Связь
Формы заявки нет: кнопки «Стать частью команды», «Хочу работать» и «Хочу начать» ведут к блоку с кнопками Telegram и WhatsApp.

## Деплой на Vercel
Статический сайт, конфиг не нужен: импортировать репозиторий в Vercel, Framework Preset — **Other**, Build Command — пусто, Output Directory — `.`.
