# Velvet touch — лендинг вакансии SPA-салона

Учебный проект для портфолио: одностраничный лендинг на чистых HTML/CSS/JS без сборки. Компания, тексты и отзывы вымышлены.

## Секции
Шапка с меню · Hero · Преимущества · FAQ (аккордеон) · Условия проживания (галерея) · Отзывы (слайдер) · Форма заявки · Футер.

## Запуск локально
```bash
npx serve .
```
Или просто откройте `index.html` в браузере.

## Структура
- `index.html` — разметка
- `styles.css` — стили и адаптив (брейкпоинты 1080 / 960 / 720 px)
- `script.js` — мобильное меню, аккордеон, слайдер, валидация формы
- `assets/img/` — фотографии (см. `assets/img/README.md`)

## Форма
Сейчас форма только проверяет поля и показывает сообщение об успехе, данные никуда не отправляются. Для реальной отправки можно подключить Formspree, Telegram-бота через serverless-функцию Vercel и т. п.

## Деплой на Vercel
Статический сайт, конфиг не нужен: импортировать репозиторий в Vercel, Framework Preset — **Other**, Build Command — пусто, Output Directory — `.`.
